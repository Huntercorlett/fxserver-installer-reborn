# 0.4.1 Beta

This patch remains a beta and is not fully tested on live servers or databases. Keep independent backups and validate it in a disposable environment before using it on an important server.

## Fixes

- Preflight now scans the selected artifact's `citizen/system_resources` as well as the profile's resources, so bundled resources such as `chat` are no longer incorrectly reported missing.
- Linked resource folders remain supported. Ambiguous copies and providers produce review warnings, and bundled resource files remain read-only diagnostic evidence.
- Incomplete resource scans report unverified references instead of false missing-resource errors. Warning limits cannot suppress known blocking findings, and resource reads reserve capacity for configuration checks.
- Start and Restart use the corrected inventory. A confirmed, one-time **Force restart** is available when a diagnostic false positive blocks restarting; cancelling leaves the running server alone.
- Health & Recovery now samples CPU, RAM, and free disk space every five seconds without requiring alerts or automatic recovery to be enabled.
- Health readings distinguish waiting, stopped, unavailable, and stale states. A blank disk folder uses the app's drive, and the sampled folder is shown on the page.
- Stale readings expire even while a status request is pending. An unavailable disk folder no longer prevents disabling alerts or recovery.

## Validation Limits

Regression coverage includes native temporary-file and process fixtures, frontend tests, and browser workflows with mocked desktop commands. The Windows installer is built without installing it or interrupting a running server.

- Automated restart tests do not replace a real FXServer restart test with representative resources and players.
- Long-running crash recovery and installer upgrade behavior still require broader live-environment testing.
- No user databases, live services, or server resources are modified by these checks.
- Installers remain unsigned. Known upstream dependency advisories are documented in the [Security Policy](https://github.com/zoxile/fxserver-installer/blob/v0.4.1/SECURITY.md); passing an audit is not a guarantee against unknown vulnerabilities.

Report reproducible issues with version **0.4.1 Beta**, your Windows version, steps, and redacted logs using the [issue templates](https://github.com/zoxile/fxserver-installer/issues/new/choose).
